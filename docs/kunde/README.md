# Bedienungsanleitung Wandpanel

Diese Anleitung erklärt, wie du das Panel anschliesst, einrichtest und bedienst. Sie gilt für die Firmware ab Version 0.9.10.

| Dokument | Inhalt |
|---|---|
| [allgemein.md](allgemein.md) | Gilt für alle Geräte: erster Start, WLAN, Loxone Miniserver, Einstellungen, alle Funktionen, Updates, Wartung im Browser, Hilfe bei Problemen |
| [panlee.md](panlee.md) | Panlee-Panel (3,95 Zoll, Unterputz) |
| [guition.md](guition.md) | Guition-Panel (4 Zoll, Unterputz, mit Relais) |
| [sensecap_d1.md](sensecap_d1.md) | SenseCAP Indicator D1 (Tischgerät) mit Oszilloskop und Logik-Analysator |

Die installierte Firmware-Version siehst du am Panel unter **Einstellungen › System › Wartung & Update** in der Zeile „Firmware“.
