## RP2040 firmware (SenseCAP Indicator D1)

`rp2040/indicator_rp2040_scope/` is a modified version of Seeed Studio's
`indicator_rp2040` v1.0.1 (<https://github.com/Seeed-Solution/SenseCAP_Indicator_RP2040>,
GPL-3.0). The whole sketch is GPL-3.0 (`rp2040/indicator_rp2040_scope/LICENSE`,
`NOTICE`). It is a separate program on the RP2040; it talks to the ESP32-S3 only
over UART, so the ESP32 firmware is not a derivative of it.

Libraries used when building the sketch (not in this repository, installed with
arduino-cli, each under its own license): Raspberry Pi Pico Arduino core
(earlephilhower arduino-pico, LGPL-2.1 / BSD-3-Clause for the Pico SDK),
PacketSerial (MIT), Sensirion I2C SGP40 / SCD4x / Core / Gas Index Algorithm
(BSD-3-Clause), Seeed_Arduino_AHT20 (MIT), Arduino SD (GPL-3.0).
